    Práctica de Aula 3. Tipos de bases de datos y estructura de los registros biológicos

    Duración

    1 hora

    Esta práctica se realiza después de la primera parte del Tema 2, dedicada a:

    • bases de datos primarias y secundarias;
    • arquitectura y organización de recursos biológicos;
    • registros, campos, identificadores, versiones y referencias cruzadas.

    Objetivos

    • Diferenciar entre bases de datos primarias y secundarias a partir de ejemplos reales.
    • Identificar qué tipo de entidad representa un registro biológico.
    • Reconocer los principales campos de un registro.
    • Localizar identificadores, referencias, anotaciones y referencias cruzadas.
    • Diferenciar información experimental, anotada o inferida cuando el recurso lo indique.
    • Valorar qué información aporta un recurso y qué limitaciones presenta.
    • Documentar de forma clara la procedencia de la información consultada.

    Contexto

    En Bioinformática no basta con encontrar una página que contenga información relacionada con una palabra de búsqueda.

    Cada recurso organiza la información de una forma determinada y cada registro representa una entidad concreta. Antes de utilizar un dato es necesario saber:

    qué representa el registro, de dónde procede la información y cómo está organizada.

    En esta práctica se analizarán varios registros biológicos para comprender su estructura y comparar el tipo de información que ofrecen.

    Tarea 1. Identificación del recurso

    El profesorado proporcionará varios recursos o registros bioinformáticos.

    Para cada uno de ellos, completa la siguiente información:

    1. Nombre del recurso.
    2. URL principal.
    3. Institución responsable.
    4. Tipo principal de información que almacena.
    5. Tipo de entidad representada por el registro consultado.
    6. ¿Se trata principalmente de una base de datos primaria, secundaria o de un recurso que integra ambos tipos de información?
    7. Justifica brevemente la respuesta anterior.

    Tabla de trabajo

    Recurso Institución Tipo de información Entidad del registro Primaria / secundaria / mixta Justificación

    Tarea 2. Anatomía de un registro biológico

    Selecciona uno de los registros proporcionados.

    Localiza los siguientes elementos, si están disponibles:

    • identificador principal;
    • nombre o descripción;
    • organismo;
    • tipo de molécula o entidad;
    • fecha de creación o actualización;
    • versión;
    • secuencia o enlace a la secuencia;
    • función o descripción funcional;
    • referencias bibliográficas;
    • referencias cruzadas a otros recursos;
    • información sobre el nivel de revisión o curación.

    Completa la ficha:

    Recurso:
    ...

    Identificador:
    ...

    Entidad representada:
    ...

    Organismo:
    ...

    Descripción principal:
    ...

    Versión o fecha de actualización:
    ...

    Información funcional disponible:
    ...

    Referencias bibliográficas:
    ...

    Referencias cruzadas:
    ...

    Nivel de revisión o curación indicado por el recurso:
    ...

    Tarea 3. Evidencia y procedencia

    Revisa el registro seleccionado y responde:

    1. ¿Qué información parece proceder directamente de datos experimentales?
    2. ¿Qué información parece ser una anotación o interpretación?
    3. ¿El recurso distingue entre información revisada y no revisada?
    4. ¿Existe alguna indicación sobre cómo se obtuvo la información?
    5. ¿Qué parte del registro necesitarías comprobar en una publicación científica antes de utilizarla como evidencia?

    No es necesario que todos los registros contengan todos estos elementos. Si un elemento no aparece, indícalo expresamente.

    Tarea 4. Referencias cruzadas

    Localiza al menos tres referencias cruzadas desde el registro hacia otros recursos.

    Para cada una, indica:

    Recurso de destino Identificador Tipo de información que aporta

    Después responde:

    ¿Qué ventaja tiene que un registro incluya referencias cruzadas a otros recursos?

    Tarea 5. Comparación entre recursos

    Compara dos de los registros analizados y responde:

    1. ¿Representan el mismo tipo de entidad?
    2. ¿Utilizan el mismo identificador?
    3. ¿Qué información aparece en ambos?
    4. ¿Qué información aparece únicamente en uno?
    5. ¿Cuál resulta más útil para conocer el dato original?
    6. ¿Cuál resulta más útil para interpretar biológicamente la información?
    7. ¿Utilizarías uno de ellos como única fuente? Justifica la respuesta.

    Entregable

    El estudiante entregará un documento breve que incluya:

    1. La tabla de identificación de recursos.
    2. La ficha completa de un registro.
    3. Las respuestas sobre evidencia y procedencia.
    4. La tabla de referencias cruzadas.
    5. Una comparación final entre dos recursos.

    La extensión recomendada es de 1–2 páginas, sin contar capturas de pantalla si se utilizan.

    Criterios de realización

    Se valorará especialmente:

    • la identificación correcta del tipo de información;
    • la distinción entre dato y anotación;
    • la correcta interpretación de los campos del registro;
    • la capacidad para justificar las respuestas;
    • la trazabilidad de la información;
    • y la claridad del documento entregado.

    No se valorará la cantidad de información copiada de la base de datos, sino la capacidad para interpretar su estructura y explicar qué representa cada elemento.

    Preguntas de cierre

    Al finalizar la práctica, responde de forma breve:

    1. ¿Por qué un identificador es más útil que un nombre?
    2. ¿Por qué una base de datos secundaria puede ser más informativa que una primaria?
    3. ¿Qué riesgo existe si se utiliza una anotación automática como si fuera evidencia experimental?
    4. ¿Por qué las referencias cruzadas son importantes en Bioinformática?

    Idea clave

    Un registro bioinformático no es una página de información: es una representación estructurada de una entidad biológica, construida a partir de datos, anotaciones, evidencias y relaciones con otros recursos.
