    Práctica de Laboratorio 1.2. Secuencias biológicas como datos

    Duración

    1 hora

    Esta sesión continúa el repaso de Python y se centra en el tratamiento de secuencias biológicas como datos computacionales.

    Objetivos

    Al finalizar la sesión, el estudiante será capaz de:

    • Representar secuencias de ADN mediante cadenas de texto.
    • Calcular longitud y composición.
    • Calcular contenido GC.
    • Validar secuencias.
    • Obtener complementaria y reverso complementario.
    • Organizar pequeñas funciones reutilizables.

    1. Una secuencia como dato

    Una secuencia de ADN puede representarse mediante una cadena:

    sequence = "ATGCGTAAC"

    Esto permite aplicar operaciones básicas de programación.

    2. Longitud y composición

    sequence = "ATGCGTAAC"

print("Longitud:", len(sequence))
print("A:", sequence.count("A"))
print("C:", sequence.count("C"))
print("G:", sequence.count("G"))
print("T:", sequence.count("T"))

    La composición permite obtener una primera descripción del dato.

    3. Contenido GC

    El contenido GC es el porcentaje de nucleótidos G y C.

    [ GC\% = \frac{G+C}{Longitud} \times 100 ]

    En Python:

    sequence = "ATGCGTAAC"

g = sequence.count("G")
c = sequence.count("C")

gc = (g + c) / len(sequence) * 100

print(gc)

    Podemos convertirlo en una función:

    def gc_content(sequence):
    g = sequence.count("G")
    c = sequence.count("C")
    return (g + c) / len(sequence) * 100

    4. Validación

    Una secuencia de ADN básica debería contener únicamente:

    A C G T

    Podemos comprobarlo:

    def is_valid_dna(sequence):
    sequence = sequence.upper()

    for base in sequence:
        if base not in "ACGT":
            return False

    return True

    Ejemplo:

    print(is_valid_dna("ATGCC"))
print(is_valid_dna("ATGCX"))

    5. Complementaria

    Las parejas de bases son:

    A ↔ T
C ↔ G

    Podemos utilizar un diccionario:

    complement = {
    "A": "T",
    "T": "A",
    "C": "G",
    "G": "C"
}

    Y construir la secuencia complementaria:

    sequence = "ATGC"
result = ""

for base in sequence:
    result += complement[base]

print(result)

    6. Reverso complementario

    El reverso complementario se obtiene:

    1. calculando la secuencia complementaria;
    2. invirtiendo el resultado.
    def reverse_complement(sequence):
    complement = {
        "A": "T",
        "T": "A",
        "C": "G",
        "G": "C"
    }

    result = ""

    for base in sequence.upper():
        result += complement[base]

    return result[::-1]

    Ideas clave

    • Una secuencia puede ser tratada como una estructura de datos.
    • Muchas operaciones bioinformáticas básicas pueden expresarse mediante algoritmos sencillos.
    • Validar los datos antes de analizarlos evita errores posteriores.
    • La organización del código en funciones mejora la reutilización.
