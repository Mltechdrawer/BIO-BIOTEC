# Práctica de Aula 3.2. Integración funcional, rutas y enriquecimiento

## Duración

**1 hora**

Esta sesión continúa el trabajo iniciado en la **Práctica de Aula 3.1**.

## Objetivos

Al finalizar la sesión, el estudiante será capaz de:

- Integrar información funcional procedente de varias fuentes.
- Relacionar un gen o proteína con procesos y rutas biológicas.
- Interpretar resultados básicos de enriquecimiento funcional.
- Distinguir asociación funcional de causalidad.
- Preparar una síntesis rigurosa para su exposición oral.

## 1. Continuación del caso

Cada grupo utilizará el mismo gen o proteína trabajado en la sesión anterior.

El objetivo es ampliar la anotación individual y situarla en un contexto funcional más amplio.

## 2. Consulta de rutas

Utiliza **Reactome**:

https://reactome.org/

Registra:

```text
Ruta o proceso principal:
Subruta, si procede:
Entidades relacionadas:
Evidencia disponible:
```

## 3. Integración

Construye un esquema:

```text
Gen/proteína
      ↓
Función molecular
      ↓
Proceso biológico
      ↓
Ruta
      ↓
Contexto funcional
```

## 4. Interpretación de enriquecimiento

El profesorado proporcionará, cuando proceda, una pequeña lista de genes relacionada con el caso o un resultado de enriquecimiento ya generado.

Analiza:

- términos enriquecidos;
- rutas enriquecidas;
- p-value ajustado o FDR;
- genes que contribuyen a los términos principales;
- posibles redundancias.

Completa:

| Término/ruta | Fuente | Significación | Genes asociados | Interpretación |
|---|---|---:|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

## 5. Preguntas de interpretación

1. ¿Qué proceso funcional parece más relevante?
2. ¿Coincide con la anotación individual obtenida en la sesión anterior?
3. ¿Existen términos redundantes?
4. ¿Qué limitaciones tiene el enriquecimiento observado?
5. ¿Puede afirmarse causalidad a partir de estos resultados?

## 6. Preparación de la exposición

Cada grupo preparará una presentación breve que incluya:

- caso y pregunta inicial;
- principales fuentes consultadas;
- función propuesta;
- dominios y términos GO;
- rutas o enriquecimiento;
- evidencias;
- limitaciones;
- conclusión.

## 7. Entregable final

Cada grupo entregará:

- tabla funcional integrada;
- esquema gen/proteína → función → proceso → ruta;
- respuestas a las preguntas;
- conclusión final de **200–250 palabras**;
- material de apoyo para la exposición.
