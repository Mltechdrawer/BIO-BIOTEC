# Práctica de Laboratorio 3.2. Dominios y familias proteicas

## Duración

**1 hora**

## Objetivos

Al finalizar la sesión, el estudiante será capaz de:

- Analizar una proteína con InterPro.
- Identificar dominios, familias y sitios.
- Relacionar firmas funcionales con la hipótesis obtenida previamente.
- Reconocer que una proteína puede contener varios dominios.

## 1. Recurso

InterPro:

https://www.ebi.ac.uk/interpro/

Utiliza la misma proteína de la práctica anterior cuando sea posible.

## 2. Analizar la secuencia

Introduce la secuencia o identificador.

Registra:

```text
Longitud:
Familia:
Dominios:
Regiones:
Sitios:
```

## 3. Representación

Dibuja o reproduce un esquema sencillo:

```text
N-terminal | dominio A | región | dominio B | C-terminal
```

## 4. Comparación con UniProt

Comprueba si los dominios detectados coinciden con la información del registro UniProt.

Completa:

| Elemento | InterPro | UniProt | Coinciden |
|---|---|---|---|
| Familia | | | |
| Dominio 1 | | | |
| Dominio 2 | | | |
| Sitio | | | |

## 5. Interpretación

Responde:

1. ¿Qué dominio parece más informativo para la función?
2. ¿La proteína pertenece a una familia?
3. ¿Todos los dominios cubren toda la proteína?
4. ¿Qué información nueva aporta InterPro?

## 6. Entregable

Entrega:

- resultado de InterPro;
- esquema de dominios;
- tabla comparativa;
- respuesta a las cuatro preguntas.

## Ideas clave

- Una proteína puede contener varios módulos funcionales.
- Los dominios ayudan a interpretar proteínas parcialmente caracterizadas.
- La integración de fuentes aumenta la calidad de la anotación.
