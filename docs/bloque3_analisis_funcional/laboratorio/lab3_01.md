# Práctica de Laboratorio 3.1. Anotación funcional inicial de una proteína

## Duración

**1 hora**

Esta sesión inicia la práctica de laboratorio del **Bloque III. Análisis funcional y minería de datos biológicos**.

## Objetivos

Al finalizar la sesión, el estudiante será capaz de:

- Partir de una secuencia o identificador proteico.
- Localizar proteínas relacionadas.
- Utilizar información de UniProt.
- Formular una primera hipótesis funcional.
- Diferenciar evidencia e inferencia.

## 1. Caso de partida

El profesorado proporcionará una secuencia o identificador de proteína.

Registra:

```text
Identificador:
Organismo:
Longitud:
Fuente:
```

## 2. Búsqueda de proteínas relacionadas

Utiliza BLASTp o el recurso indicado para localizar secuencias similares.

Selecciona tres hits relevantes.

## 3. Consulta en UniProt

Para el hit principal revisa:

- nombre de la proteína;
- función;
- estado revisado/no revisado;
- organismo;
- evidencia;
- dominios;
- referencias.

UniProt:

https://www.uniprot.org/

## 4. Primera hipótesis funcional

Redacta una hipótesis prudente.

Ejemplo de estructura:

> La secuencia analizada podría estar relacionada con..., porque presenta..., aunque sería necesario confirmar...

## 5. Entregable

Entrega:

- tabla de hits;
- información principal de UniProt;
- evidencia localizada;
- hipótesis funcional de 100–150 palabras.

## Ideas clave

- La anotación parte de evidencias.
- La similitud ayuda, pero no garantiza función idéntica.
- UniProt permite evaluar mejor el contexto funcional.
- Una hipótesis debe reflejar el nivel de evidencia disponible.
