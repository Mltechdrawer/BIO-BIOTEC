# Práctica de Laboratorio 3.3. Gene Ontology y rutas biológicas

## Duración

**1 hora**

## Objetivos

Al finalizar la sesión, el estudiante será capaz de:

- Identificar términos Gene Ontology.
- Distinguir función molecular, proceso biológico y componente celular.
- Consultar rutas biológicas.
- Relacionar una proteína individual con su contexto funcional.

## 1. Recursos

Gene Ontology:

https://geneontology.org/

Reactome:

https://reactome.org/

## 2. Gene Ontology

A partir del gen o proteína asignado, localiza términos GO.

Completa:

| Categoría | Término | Identificador GO | Evidencia |
|---|---|---|---|
| Molecular Function | | | |
| Biological Process | | | |
| Cellular Component | | | |

## 3. Interpretación

Explica con tus palabras:

- qué actividad realiza;
- en qué proceso participa;
- dónde se localiza.

## 4. Reactome

Busca el gen o proteína en Reactome.

Registra:

```text
Ruta principal:
Proceso:
Entidades relacionadas:
```

## 5. Integración

Construye un resumen:

```text
Proteína
   ↓
Función molecular
   ↓
Proceso biológico
   ↓
Ruta
```

## 6. Entregable

Entrega:

- tabla GO;
- información de Reactome;
- esquema integrado;
- comentario final de 100 palabras.

## Ideas clave

- Gene Ontology normaliza la descripción funcional.
- Un mismo gen puede tener múltiples anotaciones.
- Reactome aporta contexto de rutas y procesos.
- La función se interpreta mejor cuando se integra información de varios recursos.
