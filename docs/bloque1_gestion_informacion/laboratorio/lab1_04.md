# Práctica de Laboratorio 1.4. Recuperación de datos biológicos reales

## Duración

**1 hora**

Esta sesión aplica los conocimientos anteriores a información obtenida de recursos bioinformáticos reales.

---

## Objetivos

Al finalizar la sesión, el estudiante será capaz de:

- Localizar un registro biológico en un recurso oficial.
- Identificar correctamente la entidad y el organismo.
- Recuperar una secuencia en formato FASTA.
- Registrar identificador y procedencia.
- Procesar la secuencia con Python.
- Diferenciar recuperación de datos y análisis.

---

# 1. Flujo de trabajo

La sesión seguirá este esquema:

**buscar → verificar → descargar → documentar → procesar**

---

# 2. Buscar

El profesorado asignará un gen o una proteína.

Utiliza un recurso oficial, por ejemplo:

- NCBI;
- EMBL-EBI;
- UniProt.

Localiza el registro correspondiente.

---

# 3. Verificar

Antes de descargar, comprueba:

- nombre;
- organismo;
- tipo de entidad;
- identificador;
- descripción;
- estado de revisión si procede.

Completa:

```text
Recurso:
Entidad:
Organismo:
Identificador:
Descripción:
```

---

# 4. Descargar

Descarga la secuencia en formato FASTA.

Guarda el fichero utilizando un nombre claro.

Ejemplo:

```text
P12345_human.fasta
```

Evita nombres como:

```text
sequence1.fasta
download.fasta
file.fasta
```

---

# 5. Documentar

Crea un pequeño fichero de texto o bloque de documentación:

```text
Recurso:
URL:
Identificador:
Organismo:
Fecha de descarga:
Formato:
Observaciones:
```

---

# 6. Procesar con Python

Utiliza las funciones desarrolladas en las sesiones anteriores para obtener:

- longitud;
- composición;
- contenido GC si se trata de ADN;
- validación;
- número de registros.

Si se trata de proteína, adapta el análisis para trabajar con aminoácidos.

---

# 7. Comparar registro y fichero

Responde:

1. ¿Qué información aparece en el registro web pero no en FASTA?
2. ¿Qué información conserva FASTA?
3. ¿Qué identificador aparece en la cabecera?
4. ¿El nombre del fichero permite identificar claramente su contenido?
5. ¿Podría otra persona repetir la descarga a partir de tu documentación?

---

# 8. Actividad práctica

## Parte A

Localiza el registro asignado.

## Parte B

Descarga FASTA.

## Parte C

Procesa la secuencia con Python.

## Parte D

Genera una salida resumida:

```text
Recurso:
Identificador:
Organismo:
Longitud:
Tipo de secuencia:
Fecha:
```

## Parte E

Guarda conjuntamente:

- FASTA;
- script;
- documentación.

---

# 9. Entregable

Entrega una carpeta con:

```text
datos/
    secuencia.fasta

codigo/
    analisis.py

README.txt
```

El `README.txt` debe incluir:

- origen de los datos;
- identificador;
- fecha;
- instrucciones para ejecutar el script;
- y breve descripción del resultado.

---

# Ideas clave

- Los datos reales deben verificarse antes de descargarse.
- Un identificador permite recuperar el mismo registro.
- Un dato sin procedencia pierde valor.
- FASTA conserva la secuencia, pero no todo el contexto.
- Código, datos y documentación forman parte del análisis.
