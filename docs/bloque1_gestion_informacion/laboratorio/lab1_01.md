# 1. Pensamiento algorítmico

Un algoritmo es una secuencia finita y ordenada de instrucciones para resolver un problema.

En Bioinformática muchos procedimientos pueden describirse mediante el esquema:

**entrada → procesamiento → salida**

Ejemplo:

**Entrada:** una secuencia de ADN.  
**Procesamiento:** contar sus nucleótidos.  
**Salida:** número de A, C, G y T.

Antes de programar conviene describir el procedimiento.

### Ejemplo

Problema: calcular la longitud de una secuencia.

Algoritmo:

1. Recibir la secuencia.
2. Contar el número de caracteres.
3. Mostrar el resultado.

En Python:

```python
sequence = "ATGCGTAAC"
length = len(sequence)
print(length)
```

# 2. Variables y tipos básicos

Una variable permite almacenar un valor.

```python
sequence = "ATGCGTAAC"
length = 9
gc_content = 55.6
valid = True
```

Tipos básicos utilizados en esta práctica:

- `str`: cadenas de texto;
- `int`: números enteros;
- `float`: números decimales;
- `bool`: valores lógicos.

Podemos comprobar el tipo de una variable:

```python
print(type(sequence))
```

---

# 3. Operaciones con cadenas

Una secuencia puede representarse inicialmente como una cadena de caracteres.

```python
sequence = "ATGCGTAAC"
```

Algunas operaciones útiles:

```python
print(len(sequence))
print(sequence[0])
print(sequence[-1])
print(sequence.count("A"))
print(sequence.upper())
```

También podemos extraer fragmentos:

```python
fragment = sequence[2:6]
print(fragment)
```

---

# 4. Condicionales

Los condicionales permiten ejecutar acciones diferentes según una condición.

```python
base = "G"

if base == "G":
    print("La base es guanina")
else:
    print("La base es otra")
```

Ejemplo de validación:

```python
base = "X"

if base in "ACGT":
    print("Base válida")
else:
    print("Base no válida")
```

---

# 5. Bucles

Un bucle permite repetir una acción.

```python
sequence = "ATGC"

for base in sequence:
    print(base)
```

Podemos utilizarlo para contar manualmente:

```python
sequence = "ATGCGTAAC"
count_a = 0

for base in sequence:
    if base == "A":
        count_a += 1

print(count_a)
```

---

# 6. Funciones

Una función agrupa instrucciones que resuelven una tarea concreta.

```python
def sequence_length(sequence):
    return len(sequence)

print(sequence_length("ATGCGTAAC"))
```

Otro ejemplo:

```python
def count_base(sequence, base):
    return sequence.count(base)

print(count_base("ATGCGTAAC", "G"))
```

Las funciones permiten:

- evitar repetir código;
- organizar mejor un programa;
- separar tareas;
- y reutilizar procedimientos.
