# 1. Lectura de ficheros

Python permite abrir un fichero con:

```python
with open("secuencia.txt") as f:
    content = f.read()

print(content)
```

También podemos leer línea a línea:

```python
with open("secuencia.txt") as f:
    for line in f:
        print(line)
```

Para eliminar saltos de línea:

```python
line = line.strip()
```

---

# 2. Estructura FASTA

Un registro FASTA contiene:

```text
>identificador descripción
SECUENCIA
```

Ejemplo:

```text
>seq01 proteína hipotética
ATGCGTAGCTAGCTAG
```

La línea que comienza por `>` es la **cabecera**.

Las líneas siguientes contienen la secuencia.

---

# 3. Leer un FASTA simple

Supongamos:

```text
>seq01
ATGCGTAA
CGTAGCTA
```

Podemos leerlo así:

```python
header = ""
sequence = ""

with open("sequence.fasta") as f:
    for line in f:
        line = line.strip()

        if line.startswith(">"):
            header = line
        else:
            sequence += line

print(header)
print(sequence)
```

# 5. FASTA con varios registros

Ejemplo:

```text
>seq01
ATGCGT
>seq02
ATTTGG
>seq03
CCGGTA
```

Una estrategia consiste en almacenar cada secuencia en un diccionario:

```python
sequences = {}
current_id = None

with open("sequences.fasta") as f:
    for line in f:
        line = line.strip()

        if line.startswith(">"):
            current_id = line[1:]
            sequences[current_id] = ""
        else:
            sequences[current_id] += line
```

Después:

```python
for identifier, sequence in sequences.items():
    print(identifier, len(sequence))
```

# Ideas clave

- FASTA es un formato sencillo y ampliamente utilizado.
- La cabecera identifica el registro.
- Una secuencia puede ocupar varias líneas.
- Los ficheros pueden contener múltiples registros.
- La lectura automática permite procesar muchas secuencias.
- La procedencia debe conservarse junto con los datos.
