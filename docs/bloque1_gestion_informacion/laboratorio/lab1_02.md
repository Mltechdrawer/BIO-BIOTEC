# 1. Una secuencia como dato

Una secuencia de ADN puede representarse mediante una cadena:

```python
sequence = "ATGCGTAAC"
```

Esto permite aplicar operaciones básicas de programación.

---

# 2. Longitud y composición

```python
sequence = "ATGCGTAAC"

print("Longitud:", len(sequence))
print("A:", sequence.count("A"))
print("C:", sequence.count("C"))
print("G:", sequence.count("G"))
print("T:", sequence.count("T"))
```

La composición permite obtener una primera descripción del dato.

---

# 3. Contenido GC

El contenido GC es el porcentaje de nucleótidos G y C.

\[
GC\% = \frac{G+C}{Longitud} \times 100
\]

En Python:

```python
sequence = "ATGCGTAAC"

g = sequence.count("G")
c = sequence.count("C")

gc = (g + c) / len(sequence) * 100

print(gc)
```

Podemos convertirlo en una función:

```python
def gc_content(sequence):
    g = sequence.count("G")
    c = sequence.count("C")
    return (g + c) / len(sequence) * 100
```

# 4. Validación

Una secuencia de ADN básica debería contener únicamente:

```text
A C G T
```

Podemos comprobarlo:

```python
def is_valid_dna(sequence):
    sequence = sequence.upper()

    for base in sequence:
        if base not in "ACGT":
            return False

    return True
```

Ejemplo:

```python
print(is_valid_dna("ATGCC"))
print(is_valid_dna("ATGCX"))
```

---

# 5. Complementaria

Las parejas de bases son:

```text
A ↔ T
C ↔ G
```

Podemos utilizar un diccionario:

```python
complement = {
    "A": "T",
    "T": "A",
    "C": "G",
    "G": "C"
}
```

Y construir la secuencia complementaria:

```python
sequence = "ATGC"
result = ""

for base in sequence:
    result += complement[base]

print(result)
```

---

# 6. Reverso complementario

El reverso complementario se obtiene:

1. calculando la secuencia complementaria;
2. invirtiendo el resultado.

```python
def reverse_complement(sequence):
    complement = {
        "A": "T",
        "T": "A",
        "C": "G",
        "G": "C"
    }

    result = ""

    for base in sequence.upper():
        result += complement[base]

    return result[::-1]
```
