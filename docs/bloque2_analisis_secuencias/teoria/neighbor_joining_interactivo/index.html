Neighbor-Joining (NJ) · Construcción paso a paso

Ejemplo didáctico con distancias ficticias entre humano (H), chimpancé (C), gorila (G) y orangután (O). NJ construye un árbol sin raíz.

Árbol construido hasta esta iteración

Secuencia de trabajo: 1. Criterio de selección → 2. Agrupación → 3. Longitudes de ramas → 4. Comprobación → 5. Actualización/resultado. En NJ, el criterio de selección es la matriz Q mientras quedan más de tres nodos; con tres nodos se realiza directamente el cierre del árbol. Las etiquetas U y V son nodos internos, no raíces.
