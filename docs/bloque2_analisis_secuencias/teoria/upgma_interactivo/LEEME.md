# Recurso interactivo UPGMA

Copia la carpeta `upgma_interactivo` dentro de `docs/bloque2_analisis_secuencias/teoria/`.

En `metodos_upgma_neighbor_joining.md` (situado también en `teoria/`) añade:

```markdown
[Explorar UPGMA paso a paso](upgma_interactivo/index.html){ target="_blank" }
```

Si no está habilitada la extensión `attr_list` de Python-Markdown, usa HTML:

```html
<a href="upgma_interactivo/index.html" target="_blank" rel="noopener noreferrer">Explorar UPGMA paso a paso</a>
```

La página es autónoma y no requiere Python ni bibliotecas externas. Sus datos son ficticios y se corresponden con las tres iteraciones descritas en el ejemplo de cuatro primates.
