# Práctica de Laboratorio 2.5. Alineamiento múltiple y árbol filogenético básico

## Duración

**1 hora**

## Objetivos

Al finalizar la sesión, el estudiante será capaz de:

- Realizar un alineamiento múltiple.
- Identificar regiones conservadas y variables.
- Generar un árbol sencillo.
- Interpretar agrupaciones básicas.
- Comprender las limitaciones de una reconstrucción filogenética elemental.

## 1. Recursos

Clustal Omega:

https://www.ebi.ac.uk/Tools/msa/clustalo/

El profesorado proporcionará varias secuencias relacionadas en formato FASTA.

## 2. Alineamiento múltiple

Carga las secuencias y ejecuta el alineamiento.

Identifica:

- posiciones conservadas;
- regiones variables;
- gaps;
- secuencias más parecidas.

## 3. Observación del alineamiento

Selecciona:

- una región muy conservada;
- una región variable.

Explica brevemente qué observas.

## 4. Árbol

Genera o visualiza el árbol asociado al alineamiento.

Registra:

```text
Secuencias utilizadas:
Número de secuencias:
Método/herramienta:
Agrupaciones principales:
```

## 5. Interpretación

Responde:

1. ¿Qué secuencias aparecen más próximas?
2. ¿Qué agrupaciones observas?
3. ¿Coinciden esas agrupaciones con lo observado en el alineamiento?
4. ¿El árbol está enraizado o no?
5. ¿Qué limitaciones tiene este análisis?

## 6. Entregable

Entrega:

- alineamiento múltiple;
- árbol;
- identificación de una región conservada y una variable;
- respuestas a las cinco preguntas;
- conclusión breve.

## Ideas clave

- El alineamiento múltiple precede habitualmente al análisis filogenético.
- El árbol representa una hipótesis de relaciones.
- La calidad del alineamiento condiciona la interpretación.
- Un árbol sencillo no debe interpretarse como reconstrucción definitiva de la historia evolutiva.
