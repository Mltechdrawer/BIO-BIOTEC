# Práctica de Laboratorio 2.2. Alineamiento global y local

## Duración

**1 hora**

## Objetivos

Al finalizar la sesión, el estudiante será capaz de:

- Diferenciar alineamiento global y local.
- Ejecutar ambos tipos de alineamiento con herramientas bioinformáticas.
- Comparar los resultados obtenidos.
- Interpretar identidad, gaps y regiones alineadas.
- Seleccionar la estrategia adecuada según la pregunta.

## 1. Recursos

Se utilizarán herramientas de alineamiento de EMBL-EBI.

Recurso principal:

https://www.ebi.ac.uk/Tools/psa/

## 2. Alineamiento global

Realiza un alineamiento global con dos secuencias proporcionadas.

Registra:

```text
Secuencia 1:
Secuencia 2:
Longitud:
Identidad:
Número de gaps:
Score:
```

Observa si el alineamiento intenta utilizar toda la longitud de ambas secuencias.

## 3. Alineamiento local

Utiliza las mismas secuencias con una herramienta de alineamiento local.

Registra los mismos elementos.

Compara:

- longitud de la región alineada;
- porcentaje de identidad;
- número de gaps;
- posición inicial y final del alineamiento.

## 5. Interpretación

Responde:

1. ¿Qué método utiliza una mayor proporción de ambas secuencias?
2. ¿Cuál detecta mejor una región conservada?
3. ¿Qué ocurriría si una secuencia fuera mucho más larga que la otra?
4. ¿Qué método elegirías para comparar dos proteínas completas muy similares?
5. ¿Qué método elegirías para buscar un dominio compartido?

## 6. Entregable

Entrega:

- resultados de ambos alineamientos;
- tabla comparativa;
- respuestas a las cinco preguntas;
- una conclusión breve.

## Ideas clave

- El alineamiento global intenta explicar la relación entre secuencias completas.
- El alineamiento local busca regiones especialmente similares.
- La elección depende de la pregunta biológica.
- Un mismo par de secuencias puede producir interpretaciones distintas según la estrategia usada.
