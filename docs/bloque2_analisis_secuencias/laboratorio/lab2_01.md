## 1. Punto de partida

Ejemplo:

```text
Secuencia A

Secuencia B

```

Antes de utilizar ninguna herramienta, observa ambas secuencias y responde:

1. ¿Tienen la misma longitud?
2. ¿Cuántas posiciones coinciden?
3. ¿Cuántas posiciones son diferentes?
4. ¿Existe alguna inserción o deleción aparente?

## 2. Comparación posición a posición

Cuando las secuencias tienen la misma longitud puede realizarse una primera comparación sencilla.

```python
seq1 = "ATGCTAGCTAAC"
seq2 = "ATGTTAGCTAAC"

matches = 0

for a, b in zip(seq1, seq2):
    if a == b:
        matches += 1

identity = matches / len(seq1) * 100

print("Coincidencias:", matches)
print("Identidad:", identity)
```

## 4. Qué ocurre si las longitudes son distintas

Considera:

```text
Secuencia A: ATGCTAGC
Secuencia B: ATGCTTAGC
```

Una comparación directa genera diferencias artificiales a partir de la inserción.

Introduce manualmente un gap:

```text
ATGCT-AGC
ATGCTTAGC
```

Responde:

- ¿qué cambia en la interpretación?
- ¿por qué el alineamiento es necesario?

## Ideas clave

- Comparar secuencias exige definir correspondencias entre posiciones.
- Una diferencia puede ser una sustitución, inserción o deleción.
- El porcentaje de identidad depende del alineamiento.
- Una comparación visual sencilla es útil para entender lo que después automatizan las herramientas.
